# Reglamento interno de reparto (borrador para conversar y votar)

> Este texto es una **propuesta**. Los porcentajes y criterios en blanco se deciden en grupo, con un voto por persona. Mientras no exista una cooperativa formalmente constituida, funciona como **acuerdo interno**.

## Principios
1. **Quien trabaja participa en las decisiones.** Las reglas de reparto las aprueba el grupo.
2. **El reparto sigue al trabajo**, no al capital.
3. **Transparencia:** una sola tabla visible para todas las personas, con ingresos, gastos y reparto.
4. **Todo el trabajo cuenta:** preparar, cocinar, guiar, registrar, difundir y limpiar valen, aunque no se vean.
5. **Reserva común:** una parte de cada actividad queda para el espacio y los imprevistos.
6. **Dinero separado:** el dinero de los proyectos no se mezcla con los fondos de AUCCA. Solo el aporte acordado pasa a AUCCA.
7. **Lo probamos y lo ajustamos:** toda regla tiene fecha de revisión.

## Reglas de funcionamiento
1. Cada actividad se registra como **proyecto**, con su oferta, ventas, producción, costos y horas.
2. Primero se pagan los **costos directos**. Quien puso dinero de su bolsillo recibe **reembolso**, con boleta o factura cuando corresponda.
3. Sobre el margen de servicios se aparta un **__ %** para AUCCA (espacio e infraestructura) y un **__ %** para fondo común.
4. Las ventas de productos se reparten así: **__ %** productor/es, **__ %** vendedor/a, **__ %** espacio (AUCCA). Punto de partida acordado para plantas: 50 / 25 / 25.
5. El resto (bolsa de trabajo) se reparte entre quienes trabajaron según el método **[A / B / C / D / E / F]** elegido para esa actividad.
6. Cada persona registra sus horas y tareas dentro de **__ días** de terminada la actividad.
7. Las horas de un **emprendimiento propio** se registran aparte de las de AUCCA.
8. Las diferencias se resuelven en reunión, con una persona un voto. Una objeción razonada obliga a mejorar la propuesta antes de decidir.
9. El escenario elegido se marca como **«Acordado»** y se congela para esa actividad. Cambios futuros crean un escenario nuevo.
10. El aporte a AUCCA se **ingresa manualmente en Finanzas** cuando llega efectivamente a AUCCA, y queda registrado en «Pagos y fondos».
11. Los pagos se informan a todas las personas y se registran con fecha y medio.
12. Este reglamento se revisa el **__ / __ / ____**.
